# تقرير التحقق — 16 سبتمبر 2026

## حالة التسليم

المسلَّم هو **مصدر نسخة اختبار المحرك VideoPocket Probe 0.1.0**. ليس التطبيق الكامل المخطط. لم يتوفر هاتف ARM64، ولم يتم تشغيل محاكي Android في هذه الجلسة.

## ما نجح فعليًا

- **7 اختبارات JUnit نجحت** لمنطق الروابط واختيار الصيغ: رفض البروتوكولات غير المسموحة وبيانات الدخول، الحفاظ على معاملات الرابط، الدقة الافتراضية و4K، اشتراط مسارين للدمج، عدم تغيير الدقة المطلوبة بصمت، اختيار الصوت/الفيديو، ورفض تعبيرات الصيغ غير الموثوقة.
- هذه الاختبارات شُغّلت بشكل مستقل باستخدام Kotlin compiler 2.0.20 المتضمن في Gradle 8.11.1 وJDK 17 وJUnit 4.13.2. ليست نتيجة تشغيل مهمة Gradle الخاصة بتطبيق أندرويد ولا تثبت ترجمة Compose أو تشغيل المحرك.
- التحقق من SHA-256 لنسخة yt-dlp 2026.08.19 المضمّنة نجح، وثبت وجود ملفات EJS داخلها.
- فحص 286 ملف ELF من حزمة library:0.18.1 لمعمارِيَّتَي ARM64 وx86_64، بما فيها Python وQuickJS والمكتبات داخل أرشيف Python: كل مقاطع PT_LOAD محاذاتها 16384 أو أكثر. هذا **فحص محاذاة ثابت فقط**؛ لا يثبت تشغيل 16KB. لم يكتمل فحص حزمة FFmpeg الأصلية لأنها لم تُنزّل.
- أرشيف السورس فُحص للتأكد من مطابقة الملفات للمصدر وعدم احتوائه على local.properties أو build أو .gradle أو مفاتيح توقيع.

## ما لم يكتمل

- `assembleDebug` لم ينجح. آخر عائق كان HTTP 403 Forbidden عند طلب مكتبتَي:
  - `io.github.junkfood02.youtubedl-android:library:0.18.1`
  - `io.github.junkfood02.youtubedl-android:ffmpeg:0.18.1`
- لذلك لم يتم إنتاج APK، ولم تكتمل مهام Android `testDebugUnitTest` أو `lintDebug` أو ترجمة واجهة Compose. لا يُقدَّم ادعاء أن بناء التطبيق الكامل نجح.
- تشغيل التطبيق والمحرك على هاتف أو محاكي، تنزيل المواقع، الدمج الفعلي، تحويل MP3، تشغيل 4K وتزامن الصوت والصورة: **غير مختبرة**.
- Google AI Studio: خطوات الاستيراد موثقة، لكن تشغيل المكتبات الأصلية داخل محاكيه غير مختبر. راجع docs/AI-STUDIO.md.

## إعادة التحقق

افتح المشروع في بيئة تستطيع الوصول إلى Maven Central وGoogle Maven، وثبّت JDK 17 وAndroid SDK 35، ثم نفّذ:

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

على ويندوز استخدم `gradlew.bat` بدلًا من `./gradlew`. إذا ظهر 403، تحقق من إمكانية وصول بيئة البناء للمستودع؛ لا تعطّل التحقق من شهادات HTTPS. بعد نجاح البناء، اتبع DEVICE-TEST.md وسجّل النتائج الفعلية قبل الانتقال للواجهة الكاملة.
