# VideoPocket — نسخة اختبار المحرك

هذه هي المرحلة الأولى من الخطة، وليست التطبيق الكامل. بناء الواجهة النهائية والطابور والتنزيل في الخلفية مشروط بنجاح اختبار هاتف ARM64. لم يتوفر هاتف أثناء التطوير؛ لذلك لم تُسجّل نجاحات تنزيل فعلية لأي موقع.

## الموجود في هذه النسخة

- مشروع Android مستقل بـKotlin وJetpack Compose، يدعم Android 10+ على ARM64 وx86_64 للمحاكي.
- واجهة فحص بالعربية والإنجليزية، وإدخال رابط واحد أو استقباله بالمشاركة.
- استخراج بيانات الفيديو والجودات، تنزيل الصيغة الأصلية، اختبار دمج مسارين إلى MKV بدون إعادة ترميز، وتحويل MP3 بمعدلات 128/192/320.
- حفظ الناتج في Downloads/VideoPocket باستخدام MediaStore بدون صلاحية تخزين شاملة.
- فحص المسارات الناتجة وتقرير JSON لا يتضمن الروابط أو العناوين.
- اختبارات وحدة للتحقق من الروابط واختيار الصيغ.

المحرك يعمل على الهاتف مباشرة ولا توجد خدمة خلفية على سيرفر. وجود مستخرج للموقع ليس ضمانًا لعمل كل رابط. استخدم مقاطع عامة قصيرة مسموحًا لك بتنزيلها.

## التثبيت والتجربة

راجع [دليل الهاتف](docs/DEVICE-TEST.md). أبق التطبيق في المقدمة أثناء الاختبار. الحد الحالي 512 ميجابايت لكل مسار، وعملية واحدة كل مرة. لا تستخدم هذه النسخة لتقييم التنزيل في الخلفية أو الاستكمال أو إدارة الطابور.

## البناء

المتطلبات: JDK 17، Android SDK Platform 35، Build Tools 35.0.0، اتصال إنترنت لتنزيل التبعيات. اضبط `JAVA_HOME` و`ANDROID_HOME` أو ملف `local.properties` المحلي. لا يحتاج البناء صلاحيات مدير نظام.

```powershell
.\gradlew.bat --no-daemon assembleDebug testDebugUnitTest lintDebug
```

على Linux/macOS:

```sh
./gradlew --no-daemon assembleDebug testDebugUnitTest lintDebug
```

APK ينتج في `app/build/outputs/apk/debug/app-debug.apk`. التوقيع تجريبي فقط؛ لا يشكل إصدار نشر نهائيًا. Gradle 8.11.1 وAndroid Gradle Plugin 8.9.2 وKotlin 2.1.20 مثبتة في المشروع.

## فصل المسؤوليات

- `core`: نماذج الفيديو والصيغ والنتائج، وسياسة الروابط واختيار المسارات.
- `engine`: تغليف yt-dlp وFFmpeg، قراءة البيانات، فحص الناتج ونشره في MediaStore.
- واجهة Compose وViewModel: تنسيق اختبار واحد وتصدير التقرير. لا توجد أوامر shell أو خيارات محرك يكتبها المستخدم.

## لم يُنفَّذ بعد

الواجهة الكاملة ذات الأربع شاشات، الصور المصغرة، Room/DataStore، طابور بتنزيلين وتحويل واحد، خدمات التنزيل بالخلفية وإشعاراتها، التعليق والاستكمال وإعادة استخراج الروابط المنتهية، اختيار مجلد بديل، تحويل MP4 مع تنبيه مسبق، وسجل دائم قابل للإدارة. هذه تأتي بعد نجاح بوابة الاختبار على الهاتف.
