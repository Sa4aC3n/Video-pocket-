# VideoPocket — مشغّل ومستخرج الوسائط المحلي الشامل (Universal Media Engine)

Video Pocket هو تطبيق أندرويد مفتوح المصدر ومبني وفق نهج **محلي أولاً (Local-First)** لاستخراج وتنزيل ومعالجة مقاطع الفيديو والملفات الصوتية والمقاطع المجتزأة (Clips) وقصص الوسائط، بدون أي اعتماد على واجهات برمجية خارجية مدفوعة (No Paid APIs / No RapidAPI).

---

## 🌟 الميزات الحالية المكتملة

1. **محرك الوسائط الشامل (Universal Media Engine)**:
   - يعمل محلياً 100% داخل التطبيق باستخدام إصدار مدمج من `yt-dlp` و`FFmpeg`.
   - استخراج وتنزيل الفيديو بأعلى الجودات المتوفرة (من SD وحتى 4K/8K حسب المصدر الحقيقي).
   - استخراج الصوت وتحويله إلى صيغة MP3 (128k / 192k / 320k) أو M4A/WebM مع الحفاظ على البيانات الوصفية.
   - دمج مسارات الفيديو والصوت المنفصلة تلقائياً عبر FFmpeg الأصلي والتحقق من سلامة الحاوية بواسطة `MediaExtractor`.

2. **مزودو المنصات (12 مزوّداً مدمجاً)**:
   - **TikTok**: فيديوهات عادية وقصيرة وصوتيات وألبومات الصور.
   - **Instagram**: مقاطع Reels والمنشورات والقصص (Stories) والمحتوى المتعدد.
   - **Facebook**: مقاطع الفيديو والـ Reels والقصص العامة.
   - **X / Twitter**: مقاطع الفيديو والصور المتحركة GIF.
   - **Reddit**: الفيديوهات المدمجة وGIF وصوتيات المنشورات.
   - **Vimeo**: مقاطع الفيديو العامة بمختلف الجودات.
   - **Dailymotion**: مقاطع الفيديو وقوائم التشغيل.
   - **Bilibili**: مقاطع الفيديو والصوتيات.
   - **SoundCloud**: المسارات الصوتية وقوائم التشغيل.
   - **Tumblr**: مقاطع الفيديو والصوتيات وGIF.
   - **Snapchat**: مقاطع Spotlight والقصص العامة.
   - **المزود العام (Universal Web)**: دعم آلاف المواقع المتوافقة مع `yt-dlp`.

3. **استوديو القص والاجتزاء (Clip Studio)**:
   - تحديد نقطة البداية والنهاية عبر خط زمني تفاعلي بمقبضين (Dual-Handle Timeline).
   - أزرار ضبط دقيقة بالثواني (±1 ثانية، ±5 ثوانٍ، أو إدخال رقمي مخصص).
   - معاينة مباشرة للمقطع المجتزأ قبل التنزيل.
   - تنزيل المقطع بدقة الإطارات المفتاحية (`--force-keyframes-at-cuts`) وتصديره مباشرة لمكتبة الوسائط.

4. **إدارة التنزيلات والطابور (Download Queue Manager)**:
   - طابور تنزيل يدعم العمليات المتزامنة في الخلفية عبر Coroutines وSupervisorJob.
   - آلة حالات كاملة (`DownloadState`): في الطابور، الاستخراج، التنزيل، الدمج، التحويل، والحفظ.
   - دعم التنزيل المجمّع (Batch Download) لروابط متعددة دفعة واحدة.
   - التحكم في المهام: إيقاف مؤقت (Pause)، استئناف (Resume)، إعادة المحاولة (Retry)، وإلغاء (Cancel).
   - إشعارات نظام فورية تعرض نسبة التقدم وسرعة التنزيل والوقت المقدر.

5. **مركز الترجمات (Subtitle Center)**:
   - فحص واستخراج ملفات الترجمة المتاحة بلغات متعددة.
   - دعم صيغ SRT وVTT وتصديرها بصيغة موحدة.

6. **مكتبة الجيب والمجموعات (Pocket Library & Collections)**:
   - تنظيم التنزيلات في مجموعات مخصصة (Collections) والمفضلة (Favorites).
   - مشغل فيديو مدمج مدعوم بمعاينة وتحكم سلس.
   - تخزين آمن لبيانات الوسائط عبر `PocketLibraryManager`.

7. **إدارة التخزين والملفات المؤقتة (Storage Manager)**:
   - حفظ مباشر في مجلد `Downloads/VideoPocket/` عبر `MediaStore` بدون الحاجة لصلاحيات التخزين الشاملة القديمة.
   - عزل كل عملية تنزيل في مجلد مؤقت مستقل (`UUID-scoped temp directory`).
   - تنظيف تلقائي للملفات المؤقتة بعد اكتمال أو فشل أو إلغاء التنزيل.
   - شاشة إدارة التخزين لعرض المساحة المستهلكة وتنظيف الذاكرة المؤقتة بنقرة واحدة.

8. **عزل الأخطاء وصحة المزودين (Health & Feature Flags)**:
   - فحص ذاتي لكل مزود (`ProviderHealthManager`) وتسجيل معدلات النجاح وزمن الاستجابة.
   - إمكانية تعطيل وتفعيل أي مزود عبر مفاتيح الميزات (`FeatureFlagsManager`).
   - عزل تام للأخطاء: فشل مزود معين لا يعطل المنظومة بل يحول الرابط تلقائياً إلى المزود العام الاحتياطي.

## 🛠️ البناء والتشغيل

- **المتطلبات**: JDK 17، Android SDK Platform 35، Android Gradle Plugin 8.9+.
- **معمارية الأجهزة**: يدعم أجهزة ARM64 (الهواتف الحقيقية) وx86_64 (محاكيات التطوير)، ويعمل على Android 10 (API 29) فما فوق.

### أوامر البناء والاختبار:

```sh
# فحص البناء وتوليد نسخة الـ Debug
./gradlew assembleDebug

# تشغيل اختبارات الوحدة وعقود المزودين
./gradlew testDebugUnitTest

# تشغيل الفحص البرمجي Lint
./gradlew lintDebug
```
